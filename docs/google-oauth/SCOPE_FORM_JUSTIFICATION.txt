de-Mail Desktop is a Windows email backup/archive utility. Users select Gmail messages and a local destination. We use gmail.readonly to read the account profile and labels, list selected message IDs, and retrieve users.messages.get(format=raw). The original RFC/MIME content is saved as local .eml files and verified against byte size and SHA-256. gmail.metadata cannot retrieve message bodies or attachments, so it cannot produce complete portable archives. Broader modification or full-mail scopes are unnecessary: the app never sends, changes, labels, or deletes Gmail messages. Gmail data travels directly from Google to the user’s device and selected folder; no Liminal/de-Mail server receives messages or tokens. Local OAuth credentials are encrypted using Windows DPAPI. Disconnect deletes the local token, and users can revoke access in their Google Account. Data is not used for ads, profiling, or AI training. Use complies with Google API Services User Data Policy, including Limited Use.
