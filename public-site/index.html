Desktop archive utility by Liminal

Your email leaves Gmail. It does not leave your control.

de-Mail Desktop copies original Gmail messages to a folder you choose, verifies every saved byte, and keeps the entire process on your Windows computer.

Production release in preparation. Public downloads will begin only after Google OAuth approval and Windows code signing are complete.

Read only

de-Mail requests permission to view Gmail. It cannot send, change, trash, or permanently delete your mail.

Local only

Messages travel from Gmail to your computer and then to the archive folder you selected. Liminal runs no message server.

Verified

Atomic writes, SHA-256 hashes, and read-back verification make the archive inspectable instead of mysterious.

Plain answers

Nothing is sent quietly.

There is no automatic telemetry. Problem reports are built locally, redacted, and shown in full before you choose whether to copy, save, or email them. Update checks read public release metadata and never download or install software automatically.
