Local-only architecture

There is no Liminal server in the message path.

Authorization

de-Mail requests exactly gmail.readonly. Google's page opens in your system browser and returns through a temporary localhost callback. The refresh credential is encrypted for the current Windows user.

Archiving

Gmail message data is streamed through bounded memory into atomic files in the folder you selected. de-Mail records SHA-256 hashes and reads saved messages back to verify them.

Diagnostics

Diagnostics use an allowlist of operation counts and platform facts. They exclude message content, subjects, attachments, credentials, authorization headers, paths, and complete account addresses. Nothing is transmitted automatically.

Updates

The update checker reads bounded metadata from a fixed public GitHub repository. It does not download or execute an update. Public production installers will be Authenticode-signed and accompanied by a SHA-256 checksum.

Report a concern

Email alex@liminalmemory.com. Do not include Gmail content, OAuth credentials, or other private material.
