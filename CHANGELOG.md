# Version history

Every public release of de-Mail Desktop is recorded here. Versions follow
major.minor.patch numbering.

## 0.2.0 - 2026-09-18

- Added an application release system with synchronized package, executable, and installer versions.
- Added a public release feed, an About page, release history, and a safe manual update check.
- Added selectable archive thirds, clearer archive progress, Help, and the illustrated tutorial.

## 0.1.0 - 2026-09-08

- Initial Windows desktop release with Google OAuth, Gmail archive selection, verification, and durable history.
