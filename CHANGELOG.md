# Version history

Every public release of de-Mail Desktop is recorded here. Versions follow
major.minor.patch numbering.

## 0.3.0 - 2026-10-12

- Safe pause and resume during archive export and verification.
- Actionable failures and destination write/free-space checks.
- Detailed archive results, report export, and retry of unresolved messages.
- Re-verify existing archives locally without connecting Google.
- Hardened release checks and production OAuth packaging.

## 0.2.0 - 2026-09-18

- Added an application release system with synchronized package, executable, and installer versions.
- Added a public release feed, an About page, release history, and a safe manual update check.
- Added selectable archive thirds, clearer archive progress, Help, and the illustrated tutorial.
- Added the Support window with PayPal, Cash App, and Venmo codes.
- Added production Google identity packaging for the reviewed local Windows build.

## 0.1.0 - 2026-09-08

- Initial Windows desktop release with Google OAuth, Gmail archive selection, verification, and durable history.
